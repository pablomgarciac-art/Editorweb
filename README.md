# Editor web visual

Editor visual de webs y plantillas en un único archivo HTML (páginas, secciones, elementos arrastrables, vista escritorio/tablet/móvil, publicar).

- `index.html`: el editor completo, se abre directamente en el navegador.
- `src/`: partes del editor. Tras editarlas, ejecuta `./build.sh` para regenerar `index.html`.
- Se puede publicar con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).
